# 잔향 · ESCAPE
Three.js 3D 전장과 2D 빌보드 스프라이트를 결합한 단일 스테이지 잠입 게임 프로토타입입니다. 외부 서버나 API 키가 필요 없습니다.

## Windows 실행
1. Node.js **22.12 이상 LTS**를 설치합니다 (https://nodejs.org).
2. ZIP 파일을 먼저 완전히 압축 해제한 뒤 `게임 실행.bat` 또는 `play.bat`를 더블클릭합니다. 최초에는 인터넷으로 의존성을 설치하고 이후 재사용합니다.
3. 브라우저가 열리면 **작전 시작**. 실행 중 터미널을 유지하고 종료할 때 Ctrl+C를 누릅니다.

수동 실행: 프로젝트 폴더에서 `npm ci`, `npm run dev`. 개발 서버가 출력하는 주소를 엽니다. 코드 수정은 Vite가 즉시 반영합니다.
배포 빌드: `npm run build` → `dist/`. 빌드 확인: `npm run preview`. HTML 파일을 직접 더블클릭하는 방식은 지원하지 않습니다.

## 조작과 목표
- A/D 또는 방향키: 이동, Space: 달리기
- S: 누르는 동안 웅크리기, Shift: 사격 자세, 마우스: 조준, 좌클릭: 선택 무기 사용
- R: 재장전, Esc: 일시정지/계속
- 초록색 표지가 있는 오른쪽 끝(56m)에 도달하면 자동 탈출합니다. 별도 E 상호작용은 없습니다.

웅크리면 콘크리트 벽이 3D 시선을 차단합니다. 황색 틈에서는 웅크려도 발각될 수 있습니다. 적 머리 위 화살표는 감시 방향입니다. 노출 → 경계 게이지 → 완전 발각 → 약 0.85초 조준 후 사격 순서로 진행됩니다. 한 발에 사망하지만 조준 중 숨으면 살 수 있습니다. Shift를 누른 채 적의 몸을 클릭해 사격하세요. 웅크린 채 Shift를 누르면 몸을 노출해 사격할 수 있습니다. 총성이 가까운 적을 경계시킵니다. 6발 탄창과 예비탄 30발, 재장전 1.5초. 무한 탄약이 아닙니다.

## 구조와 확장
`src/core` 게임 상태/입력, `src/systems` 시야/충돌, `src/rendering` 렌더러/스프라이트, `src/levels` 스테이지, `src/ui` HUD/메뉴. AI 순찰 범위·시야·속도는 `data/enemies.json`, 게임 수치는 `data/gameConfig.json`에서 조정합니다. 상태는 Patrol/Idle/Suspicious/Alert/Attack/Dead입니다. 새 맵은 level01.js와 같은 start/exit/walls 인터페이스로 추가할 수 있습니다.

캐릭터 PNG는 `public/sprites`에 있습니다. `data/spriteFrames.json`에서 프레임별 픽셀 영역·기준점·단위 크기를 지정하고 `src/rendering/sprites.js`가 UV 텍스처를 만듭니다. `animation.js`는 동작을 선택합니다. 모든 자세는 픽셀당 동일한 가로·세로 크기로 표시하여 납작해지지 않습니다. 배경 지오메트리와 제공 이미지 기반 텍스처·소품은 `src/rendering/environment.js`, 카메라와 캐릭터 배치는 `world.js`가 담당합니다. 오디오는 제공 MP3를 사용합니다.

## 검증
- `npm test`: 엄폐/틈/시야 방향/벽 총알 차단/사격/발각 지연/사망/초기화/탈출/재장전.
- `npm run build`: 번들 빌드.
- `npm run dev` 후 `node e2e/smoke.mjs`: Chromium WebGL 실행, 이동/웅크림, 메뉴, 1440×900 및 800×600 조준 투영 검증. 시스템 Chromium 경로는 `CHROMIUM_PATH`로 변경 가능.
- 현재 Linux Chromium에서 검증했습니다. Windows 배치 파일의 실제 실행 및 오디오 청취는 미검증입니다. 터치 조작은 지원하지 않습니다.

Git은 초기화되어 있습니다. `git add .` 및 `git commit`으로 기록할 수 있습니다. 원격 푸시는 사용자가 별도로 수행하세요.

## 카메라·경비 반응 업데이트
카메라를 낮추고 확대했습니다. 마우스 위치에 따라 가로 최대 1.6m, 세로 최대 0.55m만큼 부드럽게 이동하며 회전 방향은 유지합니다.
사격 후 3초 동안 다시 발사할 수 없습니다. HUD에 남은 시간이 표시됩니다. 총성은 사격 순간 화면 안에 있는 생존 경비병을 사격 위치로 집결시킵니다. 경비병은 자신의 깊이 경로를 유지하며 10초 동안 접근·수색합니다. 숨은 플레이어의 이동 위치를 자동 추적하지 않습니다.
시야 안의 시체를 발견하면 3초 동안 무전 게이지가 증가합니다. 100% 보고 완료 시 맵 전체의 생존 경비병이 경계태세가 되어 발각에 필요한 시간이 1.3초에서 0.22초로 단축됩니다. 공격 전 반응 시간과 벽 엄폐 효과는 유지됩니다. 무전자를 먼저 처치하면 해당 보고를 차단할 수 있지만 다른 경비병이 시체를 발견하면 다시 무전합니다. 경계태세는 재시작까지 유지됩니다. 관련 값은 data/gameConfig.json에서 조정합니다.

## 경비 밀도·사거리·칼 업데이트
- 경비병 6명. 각자 27m 이상에 걸친 겹치는 경로를 왕복하여 여러 벽 구간을 오갑니다. 총성 집결과 시체 무전은 유지됩니다.
- 소총 유효 사거리는 3D 거리 10m입니다. 기존에는 별도 거리 제한이 없었으며, 이제 가로 화면 폭 약 20m의 절반 수준으로 제한합니다. 화면에 보여도 범위 밖이면 맞지 않습니다. 총알 궤적도 사거리 끝에서 멈춥니다.
- 실제 발사 시 카메라가 약 0.22초 흔들린 뒤 복원됩니다. 빈 탄창·쿨다운 중 클릭은 흔들리지 않습니다.
- **휠로 칼 선택 후 클릭: 칼 기습**. 두 이동 구역이 떨어져 있으므로 벽이 끊긴 틈에서 적과 좌우 거리 1.4m 이내일 때 짧게 적 구역으로 뛰어들어 처치하고 돌아옵니다. 벽 너머 공격은 불가능합니다. 대시 도중에는 노출되며 적이 도망가면 빗나갈 수 있습니다. 총성·탄약 소비 없이 사용하며 재사용 대기시간은 1.5초입니다.
- 처치 순간 다른 생존 경비병의 실제 시야(방향·거리·벽 차단)에 들어와 있으면 목격자의 발각 게이지가 즉시 100%가 됩니다. 공격 전 반응 시간은 유지되므로 즉사 판정은 아닙니다. 이후 시체 발견·무전 시스템도 그대로 작동합니다.

## 음성·조작 업데이트
제공된 MP3 4개는 public/audio에 포함했습니다. 원본 이름과 길이 매핑은 data/voices.json에 있습니다. 의심 → Suspicious, 적 발견 → Alert, 총성 → 총성 위치 수색 반응, 무전 → Radio입니다. 무전 시간은 기존 최소 시간과 음성 길이 중 더 긴 값(현재 약 3.32초)입니다. 무전자가 죽으면 음성이 즉시 중단됩니다. 일시정지·실패·재시작 때도 음성이 정리되며, 일시정지에서 복귀하면 진행 지점부터 무전이 재개됩니다. 브라우저 자동재생 정책에 따라 시작 버튼을 눌러야 음성이 활성화됩니다.
마우스 휠로 총/칼을 전환하고 좌클릭으로 사용합니다. F 근접 공격은 제거했습니다. 총은 Shift를 누르고 있는 동안만 쏠 수 있고, S와 동시에 사용하면 웅크린 사격 자세가 됩니다. 이때 몸과 총구가 벽 위로 노출되므로 은신 효과가 사라집니다. 달리기는 Space입니다. 피격 후 쓰러지는 연출 동안 조작이 잠기고 1초 뒤 실패 화면이 표시됩니다.

## 최신 변경: S 전용 엄폐·스태미나·캐릭터 아트
- Ctrl은 게임에서 사용하지 않습니다. **S만** 웅크리기이며 S+Shift로 엄폐를 풀고 조준 사격합니다.
- A/D 또는 좌우 방향키를 같은 방향으로 **280ms 이내 두 번 누르고 유지**하면 달립니다. Space 유지도 가능합니다. 키를 놓거나 방향을 바꾸면 달리기가 해제됩니다.
- 달리기 스태미나는 4초. 달리기를 멈춘 뒤 0.8초 후 초당 0.85초씩 회복합니다. 소진 시 1초분 이상 회복하고 달리기 입력을 놓았다가 다시 입력해야 달릴 수 있습니다. 웅크림·조준 중에는 달리지 않습니다. HUD에 잔량이 표시됩니다.
- 웅크린 플레이어 바로 앞 벽의 엄폐도 검사하여 다른 구간의 틈을 비스듬히 보는 적에게 부당하게 발견되지 않도록 했습니다. 벽 끝 약 12cm와 틈에서는 노출될 수 있습니다. 가까이 노출된 플레이어를 시야각 경계 때문에 놓치는 판정도 보완했습니다. 완전 발각 뒤에는 짧은 경계 기억이 유지되지만 벽을 뚫고 사격하지 않습니다.
- 플레이어는 제공 디자인을 참고해 제작한 투명 4×6 아틀라스(public/sprites/player.png)를 사용합니다. 행 순서는 idle/crouch/walk/run/aim/shoot, 각 4프레임입니다. 적은 제공된 투명 시트(public/sprites/enemies.png)의 좌우 걷기·무전·조준·사격 프레임을 사용합니다. 프레임별 영역과 기준점은 data/spriteFrames.json, UV 로드는 src/rendering/sprites.js, 동작 선택은 animation.js에서 관리합니다. 걷기/뛰기/웅크림은 실제 다른 그림이며 단순 스케일 변경으로 대체하지 않습니다.
- 제공된 플레이어 총 소리.mp3 → player-shot.mp3, 적 사격음.mp3 → enemy-shot.mp3, 재장전.mp3 → reload.mp3로 복사했습니다. 기존 합성 총성을 교체했고 기존 경비 음성·무전도 유지됩니다. 파일 변환 없이 원본 MP3를 사용합니다.
- Node 테스트와 Chromium에서 자산 로드, 여섯 동작별 프레임 선택, 세 MP3 재생 진행, S+Shift 사격을 검증했습니다. Windows 실기 및 실제 스피커 청취는 미검증입니다.

## 프레임 경계·애니메이션·배경 수정
- 이전의 웅크릴 때 세로 크기를 1.45로 줄이던 코드를 제거했습니다. 각 프레임은 원본 픽셀 비율을 유지하며, 실제로 구부린 자세의 이미지로만 낮아집니다.
- 일정한 격자로 나누지 않고 프레임별 영역·기준점을 지정했습니다. 적 좌우 순찰은 원본 마지막 프레임 자체가 잘려 있어 해당 프레임을 제외한 7프레임을 사용합니다. 플레이어 발사는 첫 칸 밖까지 뻗는 총구 화염도 포함합니다. 텍스처는 반 픽셀 여백과 Nearest 필터로 이웃 영역 번짐을 막습니다.
- 참고 이미지로 제작한 player-extra.png에 앉아 걷기 4프레임과 피격→무릎 꿇기→쓰러짐→누운 자세 4프레임을 추가했습니다. 쓰러짐은 회전으로 대체하지 않으며 1초 뒤 실패 화면이 나타나기 전 최종 자세가 표시됩니다.
- public/environment의 제공 자료를 사용해 3D 바닥·폐허 건물·엄폐벽에 재질을 적용했습니다. 원경은 참고 이미지 평면, 가까운 건물은 바닥판·기둥·벽을 조합한 3D 메시이며 창·폐허 벽면과 소품을 알파 이미지로 보완합니다. 소품은 시각 장식이며 기존 이동 경로와 엄폐 충돌은 level01.js의 3D 벽을 사용합니다. 시각적으로 부서진 벽면으로 인해 실제 엄폐 구간이 바뀌지 않도록 온전한 낮은 벽 패널을 사용합니다.
- 자동 검증: 프레임 영역·기준점·이웃 겹침, 앉아 걷기 및 사망 프레임 순서, 브라우저에서 모든 프레임의 가로·세로 픽셀 비율과 UV 범위. Chromium 화면에서 앉아 걷기·쓰러진 자세·적 6명 및 배경을 별도 캡처해 확인했습니다.

## 야간 조명·단일 음성 채널
- 푸른 저조도 환경광과 어두운 안개를 기본으로 사용합니다. 6/19/34/48m의 가로등은 따뜻한 조명으로 거리와 엄폐 구간을 비추며 일부 건물 창에도 작은 조명을 배치했습니다. 캐릭터도 조명 구역에 맞춰 밝기를 조정합니다. 조명 설정은 src/rendering/nightLighting.js에 있습니다. 조명은 시각 연출이며 적 시야 판정 수치는 변경하지 않습니다.
- 적 대사와 무전은 전체에서 동시에 한 명만 재생합니다. 우선순위는 무전 > 발견 > 총성 반응 > 의심입니다. 같은 우선순위는 현재 화자를 유지하며, 일반 반응이 겹치면 나머지 대사는 버립니다(순차 재생 대기열 없음). 화자가 죽거나 일시정지/재시작하면 중단됩니다. 다른 무전자가 있으면 그 무전 진행 지점부터 이어서 들립니다. 총성·재장전 같은 효과음은 음성 채널과 별개입니다.
