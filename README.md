# 이스케이프 워 · ESCAPE WAR
Three.js 3D 전장과 2D 빌보드 스프라이트를 결합한 3개 스테이지 잠입 게임 프로토타입입니다. 외부 서버나 API 키가 필요 없습니다.

## Windows 실행
1. Node.js **22.12 이상 LTS**를 설치합니다 (https://nodejs.org).
2. ZIP 파일을 먼저 완전히 압축 해제한 뒤 `게임 실행.bat` 또는 `play.bat`를 더블클릭합니다. 최초에는 인터넷으로 의존성을 설치하고 이후 재사용합니다.
3. 브라우저가 열리면 **작전 시작**. 실행 중 터미널을 유지하고 종료할 때 Ctrl+C를 누릅니다.

수동 실행: 프로젝트 폴더에서 `npm ci`, `npm run dev`. 개발 서버가 출력하는 주소를 엽니다. 코드 수정은 Vite가 즉시 반영합니다.
배포 빌드: `npm run build` → `dist/`. 빌드 확인: `npm run preview`. HTML 파일을 직접 더블클릭하는 방식은 지원하지 않습니다.

## 조작과 목표
- A/D 또는 방향키: 이동, Space: 달리기
- S: 누르는 동안 웅크리기, Shift: 사격 자세, 마우스: 조준, 좌클릭: 총기 사격, F: 즉시 칼 공격
- Q: 바라보는 방향으로 대시, S+Q: 구르기. 이동 입력이 있으면 그 방향을 사용합니다.
- R: 재장전, Esc: 일시정지/계속
- 각 구역의 목표를 수행한 뒤 오른쪽 건물 문·터널로 탈출합니다. 클리어 화면의 다음 작전 버튼으로 진행합니다.

웅크리면 콘크리트 벽이 3D 시선을 차단합니다. 황색 틈에서는 웅크려도 발각될 수 있습니다. 적의 발각 게이지가 오르는 동안 머리 위 느낌표가 표시됩니다. 노출 → 경계 게이지 → 완전 발각 → 약 0.85초 조준 후 사격 순서로 진행됩니다. 체력은 3칸이며 세 발에 사망합니다. 완전히 발각되기 전에는 숨으면 게이지가 줄어들지만, 100% 발각 뒤에는 앉아도 발각 상태가 유지됩니다. 완전 발각 후 적 탄환은 엄폐를 관통하며 플레이어 탄환은 벽에 막힙니다. Shift를 누른 채 적의 몸을 클릭해 사격하세요. 웅크린 채 Shift를 누르면 몸을 노출해 사격할 수 있습니다. 총성이 가까운 적을 경계시킵니다. 6발 탄창과 예비탄 30발, 재장전 1.5초. 무한 탄약이 아닙니다.

## 구조와 확장
`src/core` 게임 상태/입력, `src/systems` 시야/충돌, `src/rendering` 렌더러/스프라이트, `src/levels` 스테이지, `src/ui` HUD/메뉴. AI 순찰 범위·시야·속도는 `data/enemies.json`, 게임 수치는 `data/gameConfig.json`에서 조정합니다. 상태는 Patrol/Idle/Suspicious/Alert/Attack/Dead입니다. `src/levels/campaign.js`의 levels 배열에 start/exit/walls/guards/panels/lamps 데이터를 추가하여 새 맵을 구성합니다. 목표·상호작용 판정은 systems/stageObjects.js, 스테이지 오브젝트 외형은 rendering/stageView.js로 분리했습니다.

캐릭터 PNG는 `public/sprites`에 있습니다. `data/spriteFrames.json`에서 프레임별 픽셀 영역·기준점·단위 크기를 지정하고 `src/rendering/sprites.js`가 UV 텍스처를 만듭니다. `animation.js`는 동작을 선택합니다. 모든 자세는 픽셀당 동일한 가로·세로 크기로 표시하여 납작해지지 않습니다. 배경 지오메트리와 제공 이미지 기반 텍스처·소품은 `src/rendering/environment.js`, 카메라와 캐릭터 배치는 `world.js`가 담당합니다. 오디오는 제공 MP3를 사용합니다.

## 검증
- `npm test`: 엄폐/틈/시야 방향/벽 총알 차단/사격/발각 지연/사망/초기화/탈출/재장전.
- `npm run build`: 번들 빌드.
- `npm run dev` 후 `node e2e/smoke.mjs`: Chromium WebGL 실행, 이동/웅크림, 메뉴, 1440×900 및 800×600 조준 투영 검증. 시스템 Chromium 경로는 `CHROMIUM_PATH`로 변경 가능.
- 현재 Linux Chromium에서 검증했습니다. Windows 배치 파일의 실제 실행 및 오디오 청취는 미검증입니다. 터치 조작은 아래 모바일 실행 방법을 참고하세요.

Git은 초기화되어 있습니다. `git add .` 및 `git commit`으로 기록할 수 있습니다. 원격 푸시는 사용자가 별도로 수행하세요.

## 카메라·경비 반응 업데이트
카메라를 낮추고 확대했습니다. 마우스 위치에 따라 가로 최대 1.6m, 세로 최대 0.55m만큼 부드럽게 이동하며 회전 방향은 유지합니다.
사격 후 3초 동안 다시 발사할 수 없습니다. HUD에 남은 시간이 표시됩니다. 총성은 사격 순간 화면 안에 있는 생존 경비병을 사격 위치로 집결시킵니다. 경비병은 자신의 깊이 경로를 유지하며 10초 동안 접근·수색합니다. 숨은 플레이어의 이동 위치를 자동 추적하지 않습니다.
시야 안의 시체를 발견하면 3초 동안 무전 게이지가 증가합니다. 100% 보고 완료 시 맵 전체의 생존 경비병이 경계태세가 되어 발각에 필요한 시간이 1.3초에서 0.22초로 단축됩니다. 공격 전 반응 시간과 벽 엄폐 효과는 유지됩니다. 무전자를 먼저 처치하면 해당 보고를 차단할 수 있지만 다른 경비병이 시체를 발견하면 다시 무전합니다. 경계태세는 재시작까지 유지됩니다. 관련 값은 data/gameConfig.json에서 조정합니다.

## 경비 밀도·사거리·칼 업데이트
- 경비병 6명. 각자 27m 이상에 걸친 겹치는 경로를 왕복하여 여러 벽 구간을 오갑니다. 총성 집결과 시체 무전은 유지됩니다.
- 소총 유효 사거리는 3D 거리 10m입니다. 기존에는 별도 거리 제한이 없었으며, 이제 가로 화면 폭 약 20m의 절반 수준으로 제한합니다. 화면에 보여도 범위 밖이면 맞지 않습니다. 총알 궤적도 사거리 끝에서 멈춥니다.
- 실제 발사 시 카메라가 약 0.22초 흔들린 뒤 복원됩니다. 빈 탄창·쿨다운 중 클릭은 흔들리지 않습니다.
- **F: 칼 기습**. 두 이동 구역이 떨어져 있으므로 벽이 끊긴 틈에서 적과 좌우 거리 1.4m 이내일 때 짧게 적 구역으로 뛰어들어 처치하고 돌아옵니다. 벽 너머 공격은 불가능합니다. 대시 도중에는 노출되며 적이 도망가면 빗나갈 수 있습니다. 총성·탄약 소비 없이 사용하며 재사용 대기시간은 1.5초입니다.
- 처치 순간 다른 생존 경비병의 실제 시야(방향·거리·벽 차단)에 들어와 있으면 목격자의 발각 게이지가 즉시 100%가 됩니다. 공격 전 반응 시간은 유지되므로 즉사 판정은 아닙니다. 이후 시체 발견·무전 시스템도 그대로 작동합니다.

## 음성·조작 업데이트
제공된 MP3 4개는 public/audio에 포함했습니다. 원본 이름과 길이 매핑은 data/voices.json에 있습니다. 의심 → Suspicious, 적 발견 → Alert, 총성 → 총성 위치 수색 반응, 무전 → Radio입니다. 무전 시간은 기존 최소 시간과 음성 길이 중 더 긴 값(현재 약 3.32초)입니다. 무전자가 죽으면 음성이 즉시 중단됩니다. 일시정지·실패·재시작 때도 음성이 정리되며, 일시정지에서 복귀하면 진행 지점부터 무전이 재개됩니다. 브라우저 자동재생 정책에 따라 시작 버튼을 눌러야 음성이 활성화됩니다.
총은 좌클릭, 칼은 F 키로 즉시 사용합니다. 마우스 휠 무기 전환은 제거했습니다. 총은 Shift를 누르고 있는 동안만 쏠 수 있고, S와 동시에 사용하면 웅크린 사격 자세가 됩니다. 이때 몸과 총구가 벽 위로 노출되므로 은신 효과가 사라집니다. 달리기는 Space입니다. 피격 후 쓰러지는 연출 동안 조작이 잠기고 1초 뒤 실패 화면이 표시됩니다.

## 최신 변경: S 전용 엄폐·스태미나·캐릭터 아트
- Ctrl은 게임에서 사용하지 않습니다. **S만** 웅크리기이며 S+Shift로 엄폐를 풀고 조준 사격합니다.
- A/D 또는 좌우 방향키를 같은 방향으로 **280ms 이내 두 번 누르고 유지**하면 달립니다. Space 유지도 가능합니다. 키를 놓거나 방향을 바꾸면 달리기가 해제됩니다.
- 달리기 스태미나는 4초. 달리기를 멈춘 뒤 0.8초 후 초당 0.85초씩 회복합니다. 소진 시 1초분 이상 회복하고 달리기 입력을 놓았다가 다시 입력해야 달릴 수 있습니다. 웅크림·조준 중에는 달리지 않습니다. HUD에 잔량이 표시됩니다.
- 웅크린 플레이어 바로 앞 벽의 엄폐도 검사하여 다른 구간의 틈을 비스듬히 보는 적에게 부당하게 발견되지 않도록 했습니다. 벽 끝 약 12cm와 틈에서는 노출될 수 있습니다. 가까이 노출된 플레이어를 시야각 경계 때문에 놓치는 판정도 보완했습니다. 완전 발각 뒤에는 짧은 경계 기억이 유지되지만 벽을 뚫고 사격하지 않습니다.
- 플레이어는 제공 디자인을 참고해 제작한 투명 4×6 아틀라스(public/sprites/player.png)를 사용합니다. 행 순서는 idle/crouch/walk/run/aim/shoot, 각 4프레임입니다. 적은 제공된 투명 시트(public/sprites/enemies.png)의 좌우 걷기·무전·조준·사격 프레임을 사용합니다. 프레임별 영역과 기준점은 data/spriteFrames.json, UV 로드는 src/rendering/sprites.js, 동작 선택은 animation.js에서 관리합니다. 걷기/뛰기/웅크림은 실제 다른 그림이며 단순 스케일 변경으로 대체하지 않습니다.
- 제공된 플레이어 총 소리.mp3 → player-shot.mp3, 적 사격음.mp3 → enemy-shot.mp3, 재장전.mp3 → reload.mp3로 복사했습니다. 기존 합성 총성을 교체했고 기존 경비 음성·무전도 유지됩니다. 파일 변환 없이 원본 MP3를 사용합니다.
- Node 테스트와 Chromium에서 자산 로드, 여섯 동작별 프레임 선택, 세 MP3 재생 진행, S+Shift 사격을 검증했습니다. Windows 실기 및 실제 스피커 청취는 미검증입니다.

## 프레임 경계·애니메이션·배경 수정
- 이전의 웅크릴 때 세로 크기를 1.45로 줄이던 코드를 제거했습니다. 각 프레임은 원본 픽셀 비율을 유지하며, 실제로 구부린 자세의 이미지로만 낮아집니다.
- 일정한 격자로 나누지 않고 프레임별 영역·기준점을 지정했습니다. 적 좌우 순찰은 원본 마지막 프레임 자체가 잘려 있어 해당 프레임을 제외한 7프레임을 사용합니다. 플레이어 발사는 첫 칸 밖까지 뻗는 총구 화염도 포함합니다. 텍스처는 반 픽셀 여백과 Nearest 필터로 이웃 영역 번짐을 막습니다.
- 참고 이미지로 제작한 player-extra.png에 앉아 걷기 4프레임과 피격→무릎 꿇기→쓰러짐→누운 자세 4프레임을 추가했습니다. 쓰러짐은 회전으로 대체하지 않으며 1초 뒤 실패 화면이 나타나기 전 최종 자세가 표시됩니다.
- public/environment의 제공 자료를 사용해 3D 바닥·폐허 건물·엄폐벽에 재질을 적용했습니다. 원경은 참고 이미지 평면, 가까운 건물은 바닥판·기둥·벽을 조합한 3D 메시이며 창·폐허 벽면과 소품을 알파 이미지로 보완합니다. 소품은 시각 장식이며 기존 이동 경로와 엄폐 충돌은 level01.js의 3D 벽을 사용합니다. 시각적으로 부서진 벽면으로 인해 실제 엄폐 구간이 바뀌지 않도록 온전한 낮은 벽 패널을 사용합니다.
- 자동 검증: 프레임 영역·기준점·이웃 겹침, 앉아 걷기 및 사망 프레임 순서, 브라우저에서 모든 프레임의 가로·세로 픽셀 비율과 UV 범위. Chromium 화면에서 앉아 걷기·쓰러진 자세·적 6명 및 배경을 별도 캡처해 확인했습니다.

## 야간 조명·단일 음성 채널
- 푸른 저조도 환경광과 어두운 안개를 기본으로 사용합니다. 6/19/34/48m의 가로등은 따뜻한 조명으로 거리와 엄폐 구간을 비추며 일부 건물 창에도 작은 조명을 배치했습니다. 캐릭터도 조명 구역에 맞춰 밝기를 조정합니다. 조명 설정은 src/rendering/nightLighting.js에 있습니다. 조명은 시각 연출이며 적 시야 판정 수치는 변경하지 않습니다.
- 적 대사와 무전은 전체에서 동시에 한 명만 재생합니다. 우선순위는 무전 > 발견 > 총성 반응 > 의심입니다. 같은 우선순위는 현재 화자를 유지하며, 일반 반응이 겹치면 나머지 대사는 버립니다(순차 재생 대기열 없음). 화자가 죽거나 일시정지/재시작하면 중단됩니다. 다른 무전자가 있으면 그 무전 진행 지점부터 이어서 들립니다. 총성·재장전 같은 효과음은 음성 채널과 별개입니다.

## 모바일 플레이
휴대폰 브라우저에서도 터치로 플레이할 수 있습니다. **가로 화면 권장**이며 별도 앱 설치는 필요 없습니다. ZIP과 Windows 배치 파일을 휴대폰에서 직접 실행하는 방식은 아닙니다.

1. PC와 휴대폰을 같은 Wi-Fi에 연결합니다.
2. PC에서 `play.bat` 또는 프로젝트 폴더의 `npm run dev`로 실행합니다.
3. 터미널의 `Network: http://...:5173/` 주소 중 Wi-Fi 연결 주소를 휴대폰 Chrome/Safari에서 엽니다. `localhost`는 휴대폰 자신을 가리키므로 쓰지 않습니다. 주소가 여러 개라면 Windows `ipconfig`의 Wi-Fi IPv4 주소와 일치하는 항목을 사용하세요.
4. 연결이 안 되면 PC 방화벽의 개인 네트워크용 Node.js 접근 허용과 공유기의 기기 간 통신 허용 여부를 확인합니다. PC 터미널은 플레이하는 동안 켜 둡니다. 같은 Wi-Fi 밖에서 접속하려면 별도 웹 호스팅이 필요합니다. GitHub 저장소/다운로드 링크 자체는 게임 실행 페이지가 아닙니다.

조작: ◀/▶를 누르고 이동, 달리기를 함께 누르면 스태미나를 사용합니다. 앉기는 눌러 전환하고 유지됩니다. 화면 속 목표를 터치하거나 드래그해 조준한 뒤 공격 버튼을 누릅니다. 공격을 누르는 동안 사격 자세가 적용되며 쿨다운이 끝날 때마다 발사합니다. 앉은 상태에서도 사격할 수 있지만 그동안 몸이 노출됩니다. 칼 버튼을 터치하면 즉시 근접 공격하고, 사격 버튼은 총만 사용합니다. 재장전과 일시정지도 별도 버튼이 있습니다.

터치 버튼은 HUD 갱신과 분리하여 여러 손가락을 동시에 사용할 수 있습니다. 터치 취소·앱 전환·일시정지 때 입력을 해제해 계속 달리거나 발사하는 현상을 방지합니다. 모바일 렌더링 해상도는 픽셀비 최대 1.25로 제한합니다. `node e2e/mobile.mjs`는 서버 실행 상태에서 Chromium 모바일 에뮬레이션으로 터치 사격/재장전/전환/두 손가락 달리기/터치 취소/가로·세로 버튼 배치를 검증합니다. 실제 Android/iPhone 성능과 Safari 오디오 호환성은 미검증입니다.

## 경비 아이콘·발각 유지·의심 음성
- 경비병 머리 위 상태 문구/숫자 대신 느낌표 내부가 아래부터 차오릅니다. 완전히 채워지면 붉은 느낌표가 됩니다. 무전 중에는 라디오 모양이 청록색으로 차오릅니다. 무전 시간과 중단 규칙은 유지됩니다.
- 각 경비병의 발각 게이지가 100%가 되면 해당 경비병은 죽거나 스테이지가 재시작될 때까지 발각을 유지합니다. 최초 반응 시간 뒤에는 앉아도 1.1초 간격으로 사격을 시도합니다. 시야 밖에서도 발각은 사라지지 않으며 사거리 안에서만 쏩니다. 실제 3D 벽에 막힌 총알은 벽에서 멈추고 플레이어에게 피해를 주지 않습니다.
- 처음 플레이어를 인지한 경비병은 게이지가 비어 있는 0.55초의 짧은 의심 반응을 보인 뒤 게이지를 채웁니다. 경계태세에서는 이 지연을 건너뜁니다. 의심 음성은 게이지가 비어 있는 구간에서만 들리며, 한 번이라도 게이지가 차기 시작한 경비병은 게이지가 다시 0이 되어도 의심 음성을 재생하지 않습니다. 이미 재생 중인 의심 음성도 충전 시작 시 중단됩니다. 무전·발견·총성 반응 음성은 기존의 단일 채널 우선순위를 유지합니다.
- 테스트: `npm test`에 완전 발각 후 엄폐 사격/벽 차단/빈 게이지 의심/재발각 음성 억제/아이콘 충전 표시 검증이 포함됩니다. 개발 서버 실행 후 `node e2e/indicators.mjs`로 실제 SVG 표시를 확인합니다.

## 체력 3칸·관통 사격·필요할 때만 표시되는 느낌표
- 플레이어 체력은 3칸입니다. 적 사격 한 발마다 1칸 감소하며 세 번째 피격에 쓰러집니다. 사망 후 1초 지연과 재시작 복원은 유지됩니다. 여러 경비병의 동시 사격은 각각 한 발로 계산합니다. 자동 체력 회복은 없으며 HUD에 체력과 짧은 피격 화면 효과가 표시됩니다.
- 완전히 발각된 뒤에는 경비병이 사거리 안의 플레이어에게 엄폐벽을 관통하는 사격을 합니다. 앉아서 벽 뒤에 있어도 체력이 감소합니다. 발각 전에는 기존 엄폐·시야 차단 규칙을 유지하며 플레이어의 총알은 여전히 벽에 막힙니다. 이전 문서의 적 탄환 벽 차단 설명은 이 변경으로 대체됩니다.
- 적이 경계/공격 상태일 때 몸 전체가 붉게 변하던 효과를 제거했습니다. 자연스러운 야간 조명 밝기만 적용합니다.
- 머리 위 느낌표는 게이지가 실제로 상승하는 프레임에만 표시합니다. 게이지가 비어 있거나 감소 중일 때, 완전 발각 뒤 유지 중일 때는 숨깁니다. 무전 중 라디오 아이콘은 기존처럼 표시합니다.

## 칼 동작 비율 재제작

## 탄환 투사체·엄폐 복구·함정 범위 조정
- 적 사격 간격을 1.1초에서 **0.55초**로 줄였습니다. 최초 발견 후 조준 반응 시간 0.85초는 유지하며, 발각 상태에서도 웅크려 벽 뒤에 있으면 적 탄환이 실제 벽에 막힙니다. 틈에서는 맞을 수 있고 체력은 계속 세 발입니다.
- 플레이어·적 모두 즉시 피해/긴 선 대신 짧은 탄환 오브젝트를 발사합니다. 속도는 플레이어 42m/s, 적 34m/s입니다. 탄환이 도달해야 피해·조명 파괴가 발생하며, 발사 순간의 방향으로 날아가므로 이동이나 웅크림으로 빗나가게 할 수 있습니다. 소총 사거리 10m와 재사격 대기 3초는 유지합니다.
- 매 프레임 이전 위치부터 다음 위치까지의 3D 선분과 벽/몸체를 검사해 프레임이 느려져도 벽을 통과하지 않습니다. 가장 먼저 맞은 물체에서 소멸하며 탄환은 다른 탄환과 충돌하지 않습니다. 일시정지 때 멈추고 재시작·탈출 때 제거합니다. 사격음은 발사 때, 조명 파괴음은 도착 때 재생됩니다.
- 함정 상자는 data/gameConfig.json의 trapSize(폭 3m, 높이 1.3m, 깊이 1.5m)를 그림과 충돌 범위가 함께 사용합니다. 기존 좌우 4.8m 피해 범위를 제거하고 상자 바닥 범위 안에 중심이 있는 적만 착지 순간 제압합니다. 멀리 있거나 깊이 밖인 적에게 피해를 주지 않습니다.
- src/systems/projectiles.js에서 이동/충돌, rendering/projectileView.js에서 재사용 탄환 메시를 관리합니다. tests/projectiles.test.js와 개발 서버의 node e2e/projectiles.mjs로 비행 지연, 엄폐, 큰 프레임의 벽 관통 방지, 이동으로 회피, 사거리/초기화와 함정 외형·피해 경계를 확인합니다.

## 자동 진행·옆을 향한 출입구·조명 즉시 발각
- 1·2번 구역의 출구에 들어가면 발걸음/검은 화면 뒤 **자동으로 다음 스테이지**로 넘어갑니다. 중간 완료 메뉴는 표시하지 않습니다. 마지막 3번 구역만 최종 탈출 화면을 표시합니다. 다음 배경이 준비되는 동안 검은 화면과 시간 정지를 유지합니다.

- 켜진 금빛 조명 범위에 들어가면 10m 이내 생존 경비에게 **즉시 완전 발각**됩니다. 벽 뒤 웅크림도 이 조명 경보를 피하지 못하므로 총/제어판으로 미리 끄세요. 이전의 조명 안 2배 충전 규칙을 대체합니다. 사격 전 0.85초 반응과 탄환의 벽 차단은 유지되며, 이미 완전히 발견된 경비의 인식은 조명을 꺼도 즉시 사라지지 않습니다. 반경은 lightAlertRange에서 조정합니다.

## 칼 효과음·소음 리볼버·제어판 사격
- 제공한 MP3 세 개를 public/audio/suppressed-revolver.mp3(약 0.72초), knife-swing.mp3(약 0.98초), knife-kill.mp3(약 2.72초)로 원본 그대로 추가했습니다. 칼의 타격 프레임에서 빗나가면 휘두르기만, 적 처치에 성공하면 처치 소리만 한 번 재생합니다. 제어판에는 기존 금속 타격음이 적용됩니다.
- **1: 소총 / 2: 소음 리볼버 / 마우스 휠: 두 총기 전환**. F는 계속 즉시 칼입니다. 모바일은 우측 상단 무기 전환 버튼을 사용합니다. 두 총기 모두 Shift+클릭(모바일 사격)으로 조준 사격합니다. 재장전·칼·대시 중에는 무기 교체를 막고 교체로 사격 쿨다운을 취소할 수 없습니다.
- 소음기가 붙은 **6연발 리볼버**를 보조무기로 추가했습니다. 3D 사거리 10m, 탄속 42m/s, 재사격 간격 1.2초이며 별도 탄약 6발을 캠페인 전체에서 사용합니다. **재장전·스테이지 전환·실패 후 재시작으로도 탄약이 보충되지 않습니다.** 브라우저에서 새 게임을 시작하거나 최종 탈출 후 캠페인을 처음부터 새로 시작할 때만 6발을 지급합니다. 소총의 탄창/예비탄과 독립적입니다. 권총을 선택하면 모바일 재장전 버튼은 비활성화됩니다.
- 리볼버 사격은 총성 집결을 일으키지 않습니다. 탄환으로 적·조명을 조용히 처리할 수 있지만 실제 시야, 조명 경보, 목격과 시체 무전은 그대로 작동합니다. 사격음이 조용하다고 이미 발생한 발각을 취소하지는 않습니다.
- public/sprites/player-pistol.png에 소음 리볼버를 든 서기·걷기·달리기·웅크리기·웅크려 이동·서서/앉아서 조준·서서/앉아서 사격을 넣었습니다. 프레임마다 명시적 크롭과 공통 픽셀 배율을 사용하며, 소총은 등에 멥니다. HUD는 현재 무기 탄약과 전체 리볼버 잔탄을 표시합니다.
- 함정·조명 제어판은 **칼 또는 두 총기의 탄환**으로 작동합니다. ⊞ 표시가 실제 사격 지점입니다. 탄환이 도착할 때 작동하고, 벽·앞의 적에 먼저 맞으면 차단됩니다. 이미 작동한 제어판을 다시 맞혀도 함정을 재발동하지 않으며 탄환은 소비됩니다. 탄약고의 선행 감시등 차단 조건은 유지됩니다.
- tests/sidearm.test.js와 node e2e/sidearm.mjs로 칼 두 효과음, 실제 세 MP3 재생, 독립 탄약/보충 금지, 무음 집결 억제, 제어판 투사체 충돌과 권총 스프라이트를 검증합니다. PC/모바일 회귀 테스트에 숫자·휠·터치 무기 교체와 권총 재장전 금지를 포함했습니다.

## 집 안 프롤로그·사진 속 회상·탄약 체크포인트
- 메인 메뉴의 **플레이**를 누르면 평온한 집 안에서 시작합니다. 집은 참고 이미지의 침실/소파/소파 왼쪽 책장/식탁/주방 배치를 바탕으로 3D 벽과 평면 바닥, 픽셀 가구·조명·작동 서랍으로 제작했습니다. 참고 이미지를 방 배경으로 붙이지 않았습니다. 집 안 캐릭터와 담배 피는 남자는 참고 디자인으로 새로 제작한 빌보드 스프라이트입니다.
- 집 안 조작은 **A/D·방향키 이동, E 상호작용/대사 계속, Esc 일시정지**입니다. 달리기·앉기·총·칼·대시·무기 변경을 사용하지 않습니다. 모바일에는 별도 좌우 이동/살펴보기/대사 계속/일시정지 버튼이 있습니다. 기존 전투 조작 버튼은 집 안에서 숨깁니다.
- 식탁의 남자에게 대화 → 넥타이 부탁 → 소파 왼쪽 책장 아래 서랍 열기 → 넥타이와 함께 사진이 떨어짐 → 바닥 사진 집기 순서로 진행합니다. 사진은 2초에 걸쳐 천천히 나타나며 회상 대사 후 암전·시공간 자막·전쟁 컷신을 거쳐 첫 전쟁 스테이지로 자동 전환합니다. 대사를 출력하는 중 E/계속을 누르면 현재 문장이 완성되고, 다시 누르면 다음 줄로 넘어갑니다.
- 대사는 **data/introDialogue.json**에서 화자와 문장을 수정합니다. 보내주신 아델.mp3는 public/audio/adele-type.mp3에 포함했습니다. 파일을 한 번 디코딩하고 공백을 제외한 글자가 나타날 때마다 Web Audio로 재생합니다(처음 20ms 무음 제외). 연속 타자가 여러 음성을 겹쳐 시끄럽게 만들지 않도록 직전 글자의 재생을 끊습니다. 집에서는 Midnight_at_the_Harbor.mp3를 반복 재생하고 사진을 집으면 2초 동안 볼륨을 낮춰 정지합니다.
- 구현은 src/intro/story.js(진행/타자), homeView.js(실제 3D 집/스프라이트), interface.js와 style.css(자막/사진/터치), typeVoice.js(글자 음성), experience.js(연결)로 분리했습니다. 집 스프라이트 영역은 data/introFrames.json, 이미지는 public/intro에 있습니다. 흑백 회상 컷은 제공된 사진을 바탕으로 제작했습니다. 가구 배치는 homeFurniture.js, 아틀라스 영역은 data/homeFurniture.json에서 관리합니다.
- 프롤로그 일시정지 메뉴의 **전쟁 스테이지 바로 시작**으로 프롤로그를 건너뛸 수도 있습니다. 전쟁에서 사망 후 재시작하면 프롤로그를 반복하지 않고 현재 전쟁 스테이지에서 다시 시작합니다.
- **권총 재시작 규칙을 변경했습니다.** 스테이지를 시작할 때의 잔탄을 stagePistolAmmo에 기록하고 사망 후 재시작하면 그 수로 복원합니다. 예: 2번 스테이지에 4발로 진입한 뒤 2발을 쓰고 죽으면 다시 4발입니다. 다음 스테이지는 클리어 당시의 남은 탄약을 이어받으며 재장전/추가 탄약 지급은 없습니다. 새 캠페인은 6발입니다. 이전 문서의 재시작 때에도 잔탄을 유지한다는 설명을 대체합니다.
- 소음 리볼버 달리기는 별도 public/sprites/pistol-run.png의 **새 4프레임**으로 교체했습니다. 걷기 프레임을 재사용하지 않고 접지/다리 교차/반대 접지/공중 단계를 사용합니다. 모든 프레임의 공통 배율과 기준 바닥을 유지합니다.
- 검증: tests/intro.test.js, 개발 서버에서 node e2e/intro.mjs 및 node e2e/intro-mobile.mjs(실제 메뉴→대화→서랍→사진→회상→전쟁), node e2e/sidearm.mjs(실제 재도전 버튼의 탄약 복원과 달리기 아트). 모바일은 Chromium 에뮬레이션이며 실물 기기 성능/청취는 별도 확인이 필요합니다.

## 컷신 음악과 튜토리얼
- 제공한 war-horn-and-drums 녹음은 `public/audio/cutscene-music.mp3`에 저장했습니다. 컷신 구간에서 반복 재생하고, 일시정지/탭 이탈 때 같은 위치에서 멈추며 마지막 암전에서 볼륨을 낮춘 뒤 정지합니다. 집/시공간 자막에서는 재생하지 않습니다.
- 일반 진행은 **집 → 사진 회상 → 전쟁 컷신 → 탈출 준비 튜토리얼 → 기존 세 작전**입니다. 프롤로그 일시정지 메뉴의 **튜토리얼 바로 시작**은 연습부터, **전쟁 스테이지 바로 시작**은 본 작전부터 시작합니다. 메인 메뉴는 플레이 버튼 하나를 유지합니다.
- 튜토리얼 지형은 `src/levels/tutorial.js`, 단계별 PC/모바일 안내는 `data/tutorialLessons.json`, 성공 판정은 `src/systems/tutorial.js`에서 관리합니다. 기본 세 작전 배열/진행 순서는 유지합니다.
- 연습은 엄폐 이동 → 소총 명중과 R 재장전 → 소음 리볼버 명중 → 벽 틈에서 칼 처치 → 제어판 작동 및 낙하물 제압 → 조명 차단 → 출구 순서입니다. 실제 탄환 충돌·근접 거리·장애물·제어판·조명 기능을 사용합니다.
- 연습 표적은 반격하지 않으며 현재 단계의 행동을 완료해야 다음 구역으로 이동할 수 있습니다. 잘못된 장비로 쓰러뜨린 표적은 복구하고, 필요한 후반 제어판/감시등은 해당 단계 전에는 작동하지 않습니다. 권총 탄약을 모두 낭비하면 연습 중에만 보충합니다. 본 작전은 체력 3과 새 권총 6발로 시작하고 이후 잔탄은 기존 캠페인 규칙대로 이어갑니다.
- `src/ui/tutorial.js`는 HUD 밖의 고정 안내/재시작/건너뛰기 버튼을 관리합니다. `src/rendering/tutorialView.js`는 구역 경계와 표적 표지를 배치합니다. 화면의 ◎는 현재 조준 목표입니다. 안내는 PC 키와 터치 버튼에 맞춰 변경됩니다.
- `Game.startTutorial()`은 연습을 시작하고 `reset()`은 연습 전체를 복구합니다. 완료 후 출구에 들어가면 자동으로 `startCampaign()`을 호출합니다. `startCampaign()`/일반 `nextStage()`의 기존 세 작전과 권총 체크포인트 규칙은 유지합니다.
- 검증: `tests/tutorial.test.js`, `e2e/tutorial.mjs`의 실제 PC/터치 전체 연습, `e2e/intro.mjs`의 실제 컷신 음악/튜토리얼 연결, 기존 캠페인·입력·사격 회귀 테스트.
